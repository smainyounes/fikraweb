06 · Mobile

Pensé pour le téléphone, pas seulement réduit.

  • En-tête : logo, bouton WhatsApp en icône et menu plein écran. La navigation reste à portée de pouce.
  • Hero : le texte d'abord, puis une seule capture (les trois cadres superposés deviennent illisibles en petit).
  • Liste des logiciels : elle défile horizontalement, ligne par ligne.
  • Vitrine : la liste passe au-dessus du panneau. Dans le site final, chaque ligne s'ouvre sur place (accordéon) pour éviter les allers-retours.
  • Boutons : 48 px de haut minimum, pleine largeur sur les écrans étroits dans la version finale.
