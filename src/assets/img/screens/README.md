Tips
- Use demo data only: no real customer names, phone numbers or amounts.
- Capture the application itself, without the browser's own toolbar (the frame is drawn by the site).
- Images are cropped from the top-left corner, so put the important content there.
- Export WebP at quality 80–85 to keep each file under ~200 KB.
